# ARQON / SAHARA

Двомовний сайт ARQON із каталогом зерносушарок SAHARA та інженерно-економічним калькулятором.

**Сайт:** [Українська версія](https://rubin666666.github.io/ARQON/) · [English](https://rubin666666.github.io/ARQON/en/)

## Поточний стан

- Адаптивний інтерфейс для телефона, планшета й комп’ютера; українська та англійська мови.
- Світла тема з білим фоном, сірими картками та контрастним текстом; окрема темна тема. Вибір теми зберігається.
- Шість моделей: **S9, S10, S12, S13, S16, S18**. Характеристики з наданої таблиці, детальні вікна та збільшення зображень.
- Калькулятор із компактною основною формою та розкривними розділами інвестицій, послуг і додаткових витрат.
- Підказки, повідомлення про помилки біля полів і перехід до поля, яке потрібно виправити.
- Діаграма балансу зерна, порівняння моделей таблицею на ПК та картками на телефоні.
- Збереження й поширення сценаріїв; завантаження технічного PDF українською та англійською.

**Фінансовий розрахунок поки частковий.** Невідомі параметри виробника залишаються `null`. Сайт показує доступні результати та пояснює, чого бракує; тестові коефіцієнти не використовуються в публічному калькуляторі. Код персональних заявок і доставки PDF підготовлений, але реальні CRM/email потребують окремого налаштування.

## Локальний запуск

Потрібен **Node.js 22.13 або новіший**.

```sh
npm ci
npm run dev
```

Перегляд саме статичної версії GitHub Pages:

```sh
npm run build:pages
node scripts/preview-pages.mjs
```

Адреса перегляду: `http://localhost:4173/ARQON/`.

| Команда | Призначення |
| --- | --- |
| `npm run typecheck` | Перевірка типів |
| `npm run lint:app` | Перевірка коду застосунку, бібліотек, скриптів, сервера й тестів |
| `npm test` | Перевірка розрахунків і серверних обробників |
| `npm run build:pages` | Статична збірка у `dist/client` |
| `node scripts/check-static.mjs` | Перевірка зібраних UA/EN HTML, метаданих і ресурсів |
| `npm run build` | Окрема серверна збірка Vinext; не збірка для GitHub Pages |

## Публікація

У GitHub: **Settings → Pages → Source → GitHub Actions**.

Workflow [pages.yml](.github/workflows/pages.yml) після оновлення `main` встановлює залежності, запускає перевірки, збирає та публікує сайт. Локальний типовий базовий шлях — `/ARQON`; у workflow він визначається через `PAGES_BASE_PATH`.

Статична збірка використовує React-компоненти, Vite та ReactDOMServer для окремих українського й англійського HTML. **GitHub Pages не виконує серверні обробники заявок.**

## Калькулятор

Актуальні уточнення: [режими й потужності 18.09](docs/client-2026-09-18.md), [витрати та комерційні умови 19.09](docs/client-2026-09-19.md).

- Фіксовані режими: кукурудза 25→15%, соняшник 22→7%, ріпак 13→9%. Старі посилання автоматично переводяться на поточний режим.
- Продуктивність і час роботи визначаються за висушеним зерном. Потужність електродвигунів уже враховує коефіцієнт 0,8.
- Нагрів соняшнику — до 45 °C; тепловий розрахунок доступний.
- Амортизація виключена. Порожній тариф оператора означає «не враховано»; обслуговування та постійні витрати становлять 1% ціни сушарки за сезон і деталізуються у PDF. Монтаж та додаткові інвестиції виключені.
- ARQON.UA; комерційна пропозиція діє 10 робочих днів. Технічний PDF не є комерційною пропозицією.


Активна реалізація використовує **`config/engineering.json`**, а не старий `config/calculator.json`.

Розрахунок охоплює матеріальний баланс, час роботи, потребу в енергії, паливо, електроенергію, експлуатаційні витрати, порівняння з елеватором, послуги стороннім господарствам, відкладений продаж та окупність. Кожен показник доступний лише за наявності потрібних даних.

Важливі правила:

- Продуктивність визначається за фіксованим режимом виробника; довільна вологість не підтримується.
- Еталони: кукурудза **25% → 15%, 120 °C**; соняшник **22% → 7%, 70 °C**; ріпак **13% → 9%, 80 °C**.
- Тепловий розрахунок потребує заповнених параметрів і `thermalApproved: true` для відповідної моделі після інженерного погодження.
- Тариф елеватора підтримує грн/т вхідного зерна або грн/т-% знятої вологості.
- Для послуг використовується та сама культура й вологість, що для власного зерна. Виручка та чистий прибуток розділені.
- Різниця цін відкладеного продажу застосовується до маси після сушіння; супутні витрати віднімаються окремо. Це потенційний сценарій, не гарантований прибуток.
- Окупність вимірюється в сезонах. Основна окупність = ціна сушарки / економія на власному зерні. Послуги та відкладений продаж винесені в окремі сценарії. За недодатної економії основна окупність не досягається.
- Тривалість сезону = робочі години / 20; температура довкілля 0–25 °C.
- Доставка: відстань із кроком 5 км, цілі рейси туди й назад, задані користувачем вантажність, витрата дизеля, ціна та оплата водія. 0 км виключає доставку.
- Кількість продукту на сушильному подіумі не публікується.
- Автоматична рекомендація моделі ще не активована: потрібні погоджені правила підбору.

Сценарії зберігаються під ключем `arqon-engineering-v2` і передаються параметром URL `engineering`. Підтримується перенесення основних параметрів старого `scenario`; нові поля потребують перевірки. Контактні дані не включаються до сценарію або localStorage.

Старі модулі калькулятора та загальних заявок залишені для сумісності; вони не замінюють активний інженерний калькулятор.

## PDF та заявки

**Технічний підсумок** формується у браузері без контактної форми. Він містить баланс зерна, введені параметри, технічні й економічні результати, відсутні дані та версії розрахунку. Після формування доступне також пряме посилання для збереження PDF.

**Персональний звіт** використовує окремий серверний модуль:

1. Сервер повторно розраховує й зберігає параметри та результати.
2. Користувач залишає ім’я та обраний канал зв’язку — телефон або email. Маркетингова згода окрема й необов’язкова.
3. Заявка передається в CRM; персональний PDF формується зі збереженого розрахунку. Для email потрібен налаштований сервіс доставки.

Форма доступна за наявності HTTPS `calculationEndpoint` і тексту `privacy` для вибраної мови в `config/site.json`. Поле `leadEndpoint` належить окремому обробнику загальних звернень.

Інструкція та API: [server/engineering-backend.md](server/engineering-backend.md). Приклад конфігурації: [server/engineering-wrangler.example.jsonc](server/engineering-wrangler.example.jsonc).

Для сервера потрібні сховище `CALCULATIONS`, `RATE_LIMITER`, дозволені джерела запитів, строк зберігання, URL шрифту та адаптери CRM/email. Секрети задаються на серверному хостингу, не у frontend або Git. Публікація Pages не розгортає цей сервер. Підтвердження сервісом приймання email не означає гарантованої доставки у скриньку.

Шрифт PDF: Noto Sans, ліцензія [SIL OFL](public/fonts/OFL.txt). PDF перевіряються українською та англійською, включно з кирилицею й візуальним відображенням.

## Що потрібно до повного запуску

- Фінальна перевірка клієнтом уже внесених коефіцієнтів і розрахункових результатів; режими та потужності отримані.
- Ціни обладнання й монтажу; фактичні експлуатаційні витрати вводить господарство. Зарплата оператора необов’язкова, амортизацію не додаємо.
- Реальні контакти компанії, налаштування CRM/email, серверного зберігання та тексти політик.
- Фотографії моделей і виробництва, відео, партнери та матеріали додаткового обладнання. Наявна ілюстрація спільна для серії.
- Погодження контенту й перекладів, налаштування аналітики та остаточна перевірка реальної заявки й доставки PDF.

Порожні дані не підміняються вигаданими. Аналітика потребує налаштувань і згоди користувача. Пошукова індексація контролюється `readyForIndexing` та залишається вимкненою до погодження запуску.
