# Дані клієнта для завершення ARQON

- [ ] Тексти про компанію й технологію UA/EN.
- [ ] Характеристики SAHARA 1–4: продуктивність, паливо, енергоефективність, комплектація.
- [ ] Ціни й монтаж, витрати палива/електроенергії за моделями та культурами, обслуговування, ФОТ, лабораторія, логістика, маржа зберігання.
- [ ] Остаточні варіанти списків і контрольні розрахунки калькулятора.
- [ ] Підтвердження формул і одиниць: т-% проти маси води, база маржі, сезони проти років.
- [ ] CRM, документація API/webhook та доступ до хостингу обробника заявок.
- [ ] Телефон, email, адреса в Україні, Google Maps, Telegram/WhatsApp/Viber, соцмережі.
- [ ] Опис і матеріали додаткового обладнання.
- [ ] Фотографії, YouTube/Vimeo, логотипи партнерів.
- [ ] Політика конфіденційності й умови використання.
- [ ] GA4/GTM IDs і конверсії.
- [ ] Погодження двох тем, перекладів і дозволу на індексацію.

Код містить адаптивний сайт, теми, UA/EN, меню, конфігуровані картки моделей, калькулятор, форми, адаптер CRM, PDF, галерею, підключення відео/карти/партнерів, політики, аналітику та автоматизацію GitHub Pages.

Без коефіцієнтів і CRM результати й прийом заявок не активуються. Повне виконання ТЗ потребує зазначених матеріалів клієнта.
